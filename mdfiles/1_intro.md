## 使用Python而不使用VBA的原因

- 大量結構化資料(CSV、Excel)需要定期整理與彙整
- 資料清理耗費大量人工，且容易出錯
- Python語法簡潔易讀；VBA語法較冗長
- VBA限於處理Excel檔案，Python可以處理不同檔案格式(CSV、JSON、XML、TXT)
- 處理大量資料時(數十萬筆以上)Python速度快於VBA

| | VBA | Python |
|:---|:---|:---|
| 處理大量資料 | 慢，會卡頓 | 快，pandas底層用C優化 |
| 檔案數量上限 | 受Excel視窗開關限制 | 沒有實質上限 |
| 程式碼可讀性 | 較繁瑣  | 較簡潔  |
